# SchoolOS — User Journeys

## Super Admin

Login -> organization dashboard -> branch list -> branch dashboard -> reports -> users/roles -> app configuration -> audit -> settings.

## Branch Admin

Login -> branch dashboard -> students -> classes/sections -> attendance -> fees -> exams -> reports -> staff -> communication.

## Teacher

Login -> today's timetable -> selected class -> attendance -> homework -> marks -> messages.

## Parent

Login -> children -> today's summary -> timetable -> attendance -> homework -> fees -> receipts -> exams/results -> notices -> documents.

## Student

Login -> dashboard -> timetable -> homework -> attendance -> exams/results -> notices -> documents.

## Accountant

Login -> finance dashboard -> fee structures -> invoices -> payments -> receipts -> dues -> reports.

## Librarian

Login -> library dashboard -> catalogue -> member -> issue -> return -> fine -> reports.

## Transport Manager

Login -> routes -> stops -> vehicles -> driver assignments -> student assignments -> tracking where enabled.

## Journey principles

Every journey must define:

- authentication state
- authorization scope
- loading state
- empty state
- validation
- error state
- success feedback
- audit event where relevant
- notification side effects where relevant
